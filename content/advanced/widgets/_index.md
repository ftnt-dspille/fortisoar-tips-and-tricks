Welcome to the comprehensive guide for mastering web development fundamentals and creating advanced widgets in FortiSOAR. This learning path takes you from HTML basics through AngularJS mastery.

## 🎯 Learning Path Overview

This guide is structured as a progressive learning journey. Start from the foundations and work your way up to advanced widget development.

### Phase 1: Core Web Technologies
Master the fundamental building blocks of web development that power all modern applications.

### Phase 2: JavaScript Mastery  
Develop proficiency in JavaScript, the programming language that makes web pages interactive.

### Phase 3: Advanced Concepts
Learn critical web development concepts including HTTP, APIs, and professional development practices.

### Phase 4: Framework Application
Apply your knowledge to build dynamic, interactive applications with AngularJS.

## 📚 Complete Course Modules

### 1. HTML Fundamentals
**[HTML Crash Course - Foundation for AngularJS](01-html_crash_course.md)**

Learn the markup language that structures all web content. This module covers:
- Basic HTML syntax and elements
- Forms and input types essential for AngularJS
- Semantic HTML and accessibility
- Best practices for maintainable markup

*Estimated Time: 2-3 hours*

---

### 2. JavaScript Programming
**[JavaScript Crash Course - Foundation for AngularJS](02-javascript_crash_course.md)**

Master the programming language that powers modern web applications:
- Variables, functions, and data types
- Objects and arrays manipulation
- Asynchronous programming with promises
- DOM manipulation and event handling
- Patterns used in AngularJS applications

*Estimated Time: 4-6 hours*

---

### 3. Essential Web Concepts
**[Critical Web Development Foundations](03-critical_web_foundations.md)**

Understand the broader ecosystem of web development:
- CSS styling and Bootstrap framework
- HTTP protocols and API communication
- Browser developer tools for debugging
- Client-server architecture
- Performance considerations and best practices

*Estimated Time: 3-4 hours*

---

### 4. FortiSOAR Widget Development
**[FortiSOAR Widget Development Guide](04-fortisoar_widget_guide.md)**

Apply your knowledge to create powerful FortiSOAR widgets:
- AngularJS framework deep dive
- Widget architecture and patterns
- Data binding and form validation
- Integration with FortiSOAR APIs
- Advanced widget features and customization

*Estimated Time: 6-8 hours*

---

## 🗺️ Recommended Learning Order

### Week 1: Foundation Building
1. **Day 1-2**: [HTML Crash Course](01-html_crash_course.md)

### Week 2: Application Development

## 🎯 Learning Objectives

By completing this learning path, you will be able to:

- ✅ **Build responsive web interfaces** using HTML, CSS, and JavaScript
- ✅ **Create interactive applications** with AngularJS framework
- ✅ **Develop custom FortiSOAR widgets** with advanced functionality
- ✅ **Debug and troubleshoot** web applications effectively
- ✅ **Integrate with APIs** and handle asynchronous data
- ✅ **Follow best practices** for maintainable, professional code

## 🛠️ Prerequisites

- Basic computer literacy
- Text editor or IDE (VS Code recommended)
- Web browser with developer tools
- Willingness to learn and practice

## 💡 Study Tips

### For Beginners
- Take your time with the fundamentals
- Practice coding examples as you read
- Don't skip the HTML and JavaScript modules
- Use browser developer tools frequently

### For Experienced Developers
- You may skip modules you're already comfortable with
- Focus on the AngularJS and FortiSOAR-specific content
- Pay attention to the architectural patterns and best practices

### For All Learners
- **Code along** - Don't just read, write code
- **Use the browser console** - Experiment with JavaScript concepts
- **Build projects** - Apply concepts to real problems
- **Debug actively** - Use developer tools to understand what's happening

## 🚀 Getting Started

Ready to begin your journey? Start with the [HTML Crash Course](01-html_crash_course.md) and work through each module systematically.

Each guide builds upon the previous one, so following the recommended order will give you the most comprehensive understanding.
